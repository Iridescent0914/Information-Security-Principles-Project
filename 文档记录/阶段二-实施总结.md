固定格式：

```text

```

## 2.2 Magic

固定：

```text
TJ
```

即：

```python
MAGIC = b"TJ"
```

## 2.3 Packet Type

```text
0x01 = HANDSHAKE
0x02 = DATA
0x03 = CLOSE
```

## 2.4 Sequence Number

当前项目统一约定：

```text
HANDSHAKE：0
DATA：每方向从 1 开始递增
CLOSE：0
```

阶段二只验证格式和范围，真正的数据阶段防重放在后续实现。

## 2.5 握手子类型

定义：

```text
0x01 = ClientHello
0x02 = ServerHello
0x03 = ClientKeyExchange
0x04 = ServerKeyExchange
0x05 = ClientFinished
0x06 = ServerFinished
0x07 = Alert
```

握手子类型放在 HANDSHAKE Payload 的第一个字节中。

# 3. 实现 9 字节协议头

创建：

```text
protocol.py
```

核心代码：

```python
import struct

MAGIC = b"TJ"

TYPE_HANDSHAKE = 0x01
TYPE_DATA = 0x02
TYPE_CLOSE = 0x03

HEADER_FORMAT = "!2sBIH"
HEADER_SIZE = struct.calcsize(HEADER_FORMAT)


def pack_packet(packet_type: int, sequence: int, payload: bytes) -> bytes:
    if packet_type not in (TYPE_HANDSHAKE, TYPE_DATA, TYPE_CLOSE):
        raise ValueError("invalid packet type")

    if not 0 <= sequence <= 0xFFFFFFFF:
        raise ValueError("invalid sequence number")

    if len(payload) > 0xFFFF:
        raise ValueError("payload too long")

    header = struct.pack(
        HEADER_FORMAT,
        MAGIC,
        packet_type,
        sequence,
        len(payload),
    )

    return header + payload


def unpack_packet(data: bytes):
    if len(data) < HEADER_SIZE:
        raise ValueError("packet too short")

    magic, packet_type, sequence, payload_length = struct.unpack(
        HEADER_FORMAT,
        data[:HEADER_SIZE],
    )

    if magic != MAGIC:
        raise ValueError("invalid magic")

    if packet_type not in (TYPE_HANDSHAKE, TYPE_DATA, TYPE_CLOSE):
        raise ValueError("invalid packet type")

    payload = data[HEADER_SIZE:]

    if len(payload) != payload_length:
        raise ValueError("payload length mismatch")

    return packet_type, sequence, payload
```

并加入握手子类型：

```python
HS_CLIENT_HELLO = 0x01
HS_SERVER_HELLO = 0x02
HS_CLIENT_KEY_EXCHANGE = 0x03
HS_SERVER_KEY_EXCHANGE = 0x04
HS_CLIENT_FINISHED = 0x05
HS_SERVER_FINISHED = 0x06
HS_ALERT = 0x07
```
